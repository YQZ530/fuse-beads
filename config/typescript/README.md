# TypeScript configuration

- `app.json`: application compiler settings, inherited by the root `tsconfig.json` so Next.js, editors and plain `tsc` commands can discover them.
- `warehouse-tests.json`: compiler settings for `npm run test:warehouse`.
- `app.tsbuildinfo`: generated incremental compiler cache, ignored by Git; safe to delete and regenerated by TypeScript.

Paths in these configuration files are relative to this directory. The generated `next-env.d.ts` stays at the project root for Next.js.
